# Security policy

Please report a vulnerability privately to the repository owner after the public
repository is created. Do not include secrets, private uploads, credentials, or
personal data in an issue or test fixture.

The supported development line is 0.1.x. MoonTusCore is a protocol decision
library; deployment authentication, authorization, transport security, tenant
quotas, durable storage, and content scanning remain the adapter responsibility.
See docs/security.md for the complete boundary.
